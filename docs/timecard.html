alc-hub Timecard

NFC タイムカード端末 ファームウェア書き込みツール — カードをかざすと打刻イベントを送る、営業所常設の打刻機です。 CoreS3 統合ハブは こちら、 AtomS3 印刷ブリッジは こちら。

対応機器

マイコンM5Stack Atom VoiceS3R (Atom EchoS3R / SKU C126-ECHO、8MB PSRAM)
ネットワークAtomic PoE Base (SKU A091, W5500 + PoE 給電)
カードリーダーM5 Unit NFC (SKU U216, ST25R3916) — Grove Port A

PSRAM 非搭載の AtomS3 系には焼かないでください

ここで配布しているのは Atom VoiceS3R 専用のビルドです。 PSRAM (Octal 8MB) を前提に sdkconfig を組んでいるため、 AtomS3 / AtomS3 Lite などの PSRAM 非搭載機に焼いても PSRAM 無しのまま静かに起動します (エラーは出ません)。 打刻音 (ES8311) はまだ入っていません — 別途対応します。

書き込み手順

  1. 本体を USB-C ケーブルで PC に接続 (PoE Base は外れていてもよい)
  2. 箱出しの新品は本体ボタンを押しながら挿し直す — 工場出荷ファームは USB オーディオデバイスとして動いており、 そのままではシリアルポートが出てきません
  3. 下の「Install」ボタンをクリックし、シリアルポートを選択
  4. 書き込み完了後、PoE Base に載せて LAN ケーブル (PoE) を接続し、Unit NFC を Grove に挿す
  5. シリアルに EVT NFC_READY と EVT ETH_CONNECTED <IP> が出れば疎通完了

初回インストール後はデバイス登録が必要です

書き込み直後は未登録で、AUTH STATUS が AUTH UNPAIRED を返します。 auth.ippoan.org/device/setup で「NFC タイムカード端末」を選んでデバイス登録 (登録済みなら「再登録」) してください。 再インストール (更新) では NVS 設定 (デバイス登録) は保持されます — ただし書き込みダイアログで「Erase device」を選んだ場合は消えるので、 上記の手順で再登録してください。

動作要件

  • Chrome / Edge / Opera (Web Serial API 対応ブラウザ)
  • ESP32-S3 は USB Serial/JTAG 内蔵のため追加ドライバ不要
  • シリアルポートが出てこない場合は、本体ボタンを押したまま USB を挿し直す (ROM ダウンロードモード)。工場出荷ファームや、書き込んだファームが 起動直後に落ちる状態では、これが唯一の入り口です

ファームウェアをインストール

お使いのブラウザは Web Serial API に対応していません。
Chrome, Edge, または Opera をお使いください。 シリアルポートへのアクセスが許可されていません。

動作確認 (シリアル 115200bps)

デバイス登録は auth.ippoan.org/device/setup から自動で行われます。以下は現地での切り分け用です。

  • STATUS — STATUS LAN=1 IP=192.168.x.x VER=… (LAN とファーム版数)
  • AUTH STATUS — AUTH PAIRED <tenant> <id> / AUTH UNPAIRED
  • WS STATUS — WS CONNECTED=1 QUEUE=0 SEQ=n。 カードをかざすたびに SEQ が増え、QUEUE が 0 に戻るのが正常 (QUEUE が減らないならサーバ側で弾かれています)
  • LOG DUMP — 起動直後のログ (USB 接続前に流れた分も残ります)
  • OTA <url> — 手動ファームウェア更新

カードをかざすと EVT TIMECARD card_id=… card_kind=felica_idm|license|nfca_uid が出ます。財布などにカードが 2 枚入っていて両方見えたときは、どちらの打刻か決められないので 打刻せず EVT NFC_MULTI_CARD だけを出します。

本機に LED はありません — 確認はシリアルログで

Atom VoiceS3R には RGB LED が載っていません (旧 Atom Voice の WS2812 は無くなりました)。 読めたかどうかは上の EVT ログで確認してください。 現場から見える形の反応 (打刻音) は別途対応します。

打刻が「登録されていません」になるとき

端末は読み取った 生の値を送ります (交通系 IC は大文字の IDm 16 文字、 免許証は交付日 8 桁 + 有効期限 8 桁)。管理画面のカード登録 (乗務員マスタ) に同じ文字列が入っているか確認してください。 照合は大文字・小文字を区別します。
