点呼端末の警告デバイス

点呼キオスク (ブラウザ) の異常を音で知らせる据置ブザーの ファームウェア書き込みツールです。 キオスクが 3 秒ごとに「正常」を送り、途切れたら端末が自分の判断で鳴ります。 CoreS3 統合ハブは こちら、 AtomS3 印刷ブリッジは こちら、 NFC タイムカード端末は こちら。

対応機器

マイコンM5Stack Atom VoiceS3R (Atom EchoS3R / SKU C126-ECHO、8MB PSRAM)
接続USB-C ケーブルで点呼キオスクの PC へ (給電も USB)
停止ボタン本体ボタン (G41)

PSRAM 非搭載の AtomS3 系には焼かないでください

ここで配布しているのは Atom VoiceS3R 専用のビルドです。 PSRAM (Octal 8MB) を前提に sdkconfig を組んでいるため、 AtomS3 / AtomS3 Lite などの PSRAM 非搭載機に焼いても PSRAM 無しのまま静かに起動します (エラーは出ません)。

PC の電源が落ちるとブザーも止まります

USB 給電なので、PC が完全に落ちたときは鳴りません。 これは承知の上の割り切りです (人が見れば分かる異常のため)。 ブラウザのクラッシュ・タブを閉じた・PC のフリーズ・USB を抜いた場合は、 いずれも「沈黙」として検知して鳴ります。

書き込み手順

  1. 本体を USB-C ケーブルで PC に接続
  2. 箱出しの新品は本体ボタンを押しながら挿し直す — 工場出荷ファームは USB オーディオデバイスとして動いており、 そのままではシリアルポートが出てきません
  3. 下の「Install」ボタンをクリックし、シリアルポートを選択
  4. 書き込みが終わったら、ボタンから指を離して USB を挿し直す — 押したままだと起動のたびにダウンロードモードに入り、 焼けているのにアプリが動きません
  5. 起動から 30 秒たっても点呼キオスクを開いていなければ、 「沈黙」として鳴り始めます (これが正常動作です)。 本体ボタンを押すと止まります。もう一度押すと鳴動に戻ります (ボタンはトグルです)
  6. 止めているあいだも 5 秒ごとに短く「ピッ」と鳴ります — 異常が続いていることを忘れないための合図です。 異常が解消すると自動で止まり、低い音 (ピー) が 1 回鳴ります

「焼けたのに動かない」ときに見るところ

シリアルに waiting for download や boot:0x30 (DOWNLOAD(USB/UART0)) が出ていたら、 ダウンロードモードに入ったままです。ボタンから指を離して挿し直してください (書き込みは成功しています)。

コマンドラインで確認する場合、espflash monitor に --no-reset を付けないでください — 付けると端末がフラッシュスタブに留まってアプリが起動せず、 「反応が無い」ように見えます。

デバイス登録は要りません

この端末はネットワークに出ません。サーバとの通信も デバイス登録もなく、USB ケーブル 1 本で完結します。 焼いたらそのまま使えます。

動作要件

  • Chrome / Edge / Opera (Web Serial API 対応ブラウザ)
  • ESP32-S3 は USB Serial/JTAG 内蔵のため追加ドライバ不要
  • シリアルポートが出てこない場合は、本体ボタンを押したまま USB を挿し直す (ROM ダウンロードモード)。工場出荷ファームや、書き込んだファームが 起動直後に落ちる状態では、これが唯一の入り口です

ファームウェアをインストール

お使いのブラウザは Web Serial API に対応していません。
Chrome, Edge, または Opera をお使いください。 シリアルポートへのアクセスが許可されていません。

鳴り方と止め方

場面音
警告 (鳴動中)3000Hz 200ms を 3 連 — 止まるまで 1.8 秒ごとに繰り返す
異常が解消した1200Hz 150ms を 1 発 (「直った」合図)
本体ボタンで止めた鳴らない

止めた合図を分けているのは運用上の識別のためです。 ボタンで黙らせたなら異常は続いているので人が見に行く必要があり、 勝手に止まったなら解消しているので放置でよい。 同じ音だとこの区別が現場でつきません。

ボタンで黙らせたあとは、異常が解消するまで鳴りません (人が認識済みなので蒸し返さない)。一度解消してから再発すると、また鳴ります。

鳴り出す条件

条件しきい値
キオスクからの連絡が途切れた (沈黙)最後の受信から 10 秒
電源を入れてから一度も連絡が来ない起動から 30 秒
キオスクが異常を自覚している即時 (HB NG <理由> 受信時)
点呼の呼び出しが来ている即時 (call=1 受信時)

キオスクは 3 秒ごとに送るので、10 秒は 3 回ぶんの取りこぼしを許す設定です (ブラウザの setInterval は背面タブで 1 秒までしか 絞られないため、3 秒間隔なら背面でも間に合います)。

動作確認 (シリアル 115200bps)

点呼キオスク側が自動で HB を送るので、通常は何も打つ必要はありません。 以下は現地での切り分け用です。

  • STATUS — STATUS alarm state=idle cause=none hb_age_ms=1200 VER=…。 hb_age_ms が 3000 前後で上下していればキオスクからの 連絡が届いています (増え続けるなら届いていません)
  • HB OK — 手で 1 回ぶんの「正常」を送る (鳴っていれば止まります)
  • HB NG serial — 手で「異常」を送る (鳴り始めます)
  • PING — PONG 応答
  • LOG DUMP — 起動直後のログ (USB 接続前に流れた分も残ります)

状態が変わるたび、および 5 秒ごとに EVT ALARM state=idle|alarming|muted cause=none|silence|ng:<理由>|call が出ます。キオスク側の画面表示はこの行を読んでいます。

この端末は点灯で知らせません — 反応は音だけ

Atom VoiceS3R には点灯表示がありません。 起動しても光りませんが異常ではありません。 生きているかどうかは、キオスクを閉じて 10 秒待てば鳴ることで 確かめられます。音が全く出ない場合はシリアルに EVT SPEAKER_NG が出ていないか確認してください。
