alc-hub Vein Station

指静脈読み取り端末 (Vein Station) ファームウェア書き込みツール — アルコール検知器 FC-1200・指静脈モジュール・NFC をまとめて PC に USB でつなぐ端末です。 NFC タイムカード端末は こちら。

対応機器

マイコンM5Stack Atom VoiceS3R (Atom EchoS3R / SKU C126-ECHO、8MB PSRAM)
指静脈モジュールWaveshare Finger Vein Scanner Module (A) — 中継基板の J3 (G5 / G6)
アルコール検知器タニタ FC-1200 — 中継基板の DB9 (G7 / G8)
カードリーダーM5 Unit NFC (SKU U216, ST25R3916) — Grove Port A (G2 / G1)

ボードの組み合わせに合ったものを選んでください

配線 (どのピンに何をつなぐか) はボードと筐体の組み合わせごとに違います。 下の「ボード」で、お使いの組み合わせを選んでから書き込んでください。 違うものを焼くと、指静脈や NFC が読めません。

書き込み手順

  1. 本体を USB-C ケーブルで PC に接続
  2. 箱出しの新品は本体ボタンを押しながら挿し直す — 工場出荷ファームは USB オーディオデバイスとして動いており、 そのままではシリアルポートが出てきません
  3. 下の「ボード」を選び、「Install」ボタンをクリックしてシリアルポートを選択
  4. 書き込みが終わったら、ボタンから指を離して USB を挿し直す — 押したままだと起動のたびにダウンロードモードに入り、 焼けているのにアプリが動きません
  5. NFC 版: シリアルに EVT NFC_READY が出れば NFC は使えます。 GPS 版: Unit GPS をつないで屋外 (窓際) に置くと EVT GPS FIX … が出ます。 VEIN CAPTURE で指静脈モジュールの読み取りを確かめられます

「焼けたのに動かない」ときに見るところ

シリアルに waiting for download や boot:0x30 (DOWNLOAD(USB/UART0)) が出ていたら、 ダウンロードモードに入ったままです。ボタンから指を離して挿し直してください (書き込みは成功しています)。

Unit GPS を使う GPS 版は NFC が使えません (Grove Port A を GPS が使うため)。 カードで本人確認するときは NFC 版を書いてください。

Unit NFC は電源を入れる前に挿しておいてください。 起動時に挿さっていないと EVT NFC_INIT_NG が出て、 後から挿しても再起動するまで復帰しません。

動作要件

  • Chrome / Edge / Opera (Web Serial API 対応ブラウザ)
  • ESP32-S3 は USB Serial/JTAG 内蔵のため、通常は追加ドライバ不要（Windows 10 以降 / macOS / Linux）
  • Windows 7 の PC では、そのままではシリアルポートが出てこないことがあります。警告デバイスのページの「Windows 7 の PC で使うとき」を参照し、同じ手順を試してください

血圧計をつなぐ (既定は OFF)

血圧計 (Omron HEM-6231T) は既定で無効です。 Erase 付きで書き込むと設定も消えるので、書き込むたびに下の手順を 1 → 2 の順に進めます。 ボタンを押すとシリアルポートの選択が出るので、Vein Station を選んでください (Chrome / Edge / Opera。 ファームウェアの書き込みダイアログと、alc-app を開いたタブは閉じてから — ポートを使っていると選べません)。

  1. 血圧計を使う — 端末に OMRON BP ON を送ります (OK OMRON BP=1 が返れば成功)。 Vein Station は体温計のために BLE を常に動かしているので、挿し直しは要りません。
  2. 血圧計をペアリング — 先に血圧計をペアリング待ち (オムロンは Bluetooth ボタン長押しで -P- 点滅) にしてから押します。 押すたびに本体のボンド情報を消して 120 秒の受付を開き、 その間に見つけたペアリング待ちの血圧計と組みます。 成立したら押し直さないでください (組んだボンドを消してしまいます)。

ペアリングが済んだあと、血圧計で測定すると {"type":"blood_pressure",…} がシリアルに出ます。

ボタンが効かないとき・うまくいかないとき (シリアルに手で送る手順)

Web Serial 非対応のブラウザや、ボタンで進まないときは、シリアル端末 (115200bps) から次の順に送ります:

  1. シリアルに OMRON BP ON を送る (OK OMRON BP=1 が返る)。 OMRON STATUS で今の設定 (OMRON BP=1 / OMRON BP=0) を確かめられます
  2. 血圧計をペアリング待ちにしてから PAIR を送る。 EVT PAIR_CLEARED → EVT PAIR_ARMED <秒> → EVT PAIR_OK で成立です (EVT PAIR_ERR / EVT PAIR_TIMEOUT は失敗)
  3. 測定すると {"type":"blood_pressure",…} がシリアルに出ます

ボンドは起動時に消えません

一度ペアリングすれば NVS に残るので、再起動のたびに操作は要りません。 消えるのは PAIR を明示的に送ったとき (「血圧計をペアリング」ボタンも同じ) と、 Erase 付きで書き込み直したときです。 機器を入れ替えたときは PAIR をやり直してください。

動作確認 (シリアル 115200bps)

  • DEVICE — DEVICE timecard VER=… (機種識別 + 版数)
  • VEIN CAPTURE — 指を置くと VEIN CHARA <hex>。 モジュールがつながっていなければ ERR VEIN NO_MODULE
  • OMRON STATUS — OMRON BP=1 / OMRON BP=0 (血圧計を拾うか)
  • LOG DUMP — 起動直後のログ (USB 接続前に流れた分も残ります)

コマンドの一覧と詳細は console-protocol.md を参照してください。
