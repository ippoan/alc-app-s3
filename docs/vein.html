alc-hub Vein Station

指静脈読み取り端末 (Vein Station) ファームウェア書き込みツール — アルコール検知器 FC-1200・指静脈モジュール・NFC をまとめて PC に USB でつなぐ端末です。 NFC タイムカード端末は こちら。

対応機器

マイコンM5Stack Atom VoiceS3R (Atom EchoS3R / SKU C126-ECHO、8MB PSRAM)
指静脈モジュールWaveshare Finger Vein Scanner Module (A) — 中継基板の J3 (G5 / G6)
アルコール検知器タニタ FC-1200 — 中継基板の DB9 (G7 / G8)
カードリーダーM5 Unit NFC (SKU U216, ST25R3916) — Grove Port A (G2 / G1)

ボードの組み合わせに合ったものを選んでください

配線 (どのピンに何をつなぐか) はボードと筐体の組み合わせごとに違います。 下の「ボード」で、お使いの組み合わせを選んでから書き込んでください。 違うものを焼くと、指静脈や NFC が読めません。

書き込み手順

  1. 本体を USB-C ケーブルで PC に接続
  2. 箱出しの新品は本体ボタンを押しながら挿し直す — 工場出荷ファームは USB オーディオデバイスとして動いており、 そのままではシリアルポートが出てきません
  3. 下の「ボード」を選び、「Install」ボタンをクリックしてシリアルポートを選択
  4. 書き込みが終わったら、ボタンから指を離して USB を挿し直す — 押したままだと起動のたびにダウンロードモードに入り、 焼けているのにアプリが動きません
  5. シリアルに EVT NFC_READY が出れば NFC は使えます。 VEIN CAPTURE で指静脈モジュールの読み取りを確かめられます

「焼けたのに動かない」ときに見るところ

シリアルに waiting for download や boot:0x30 (DOWNLOAD(USB/UART0)) が出ていたら、 ダウンロードモードに入ったままです。ボタンから指を離して挿し直してください (書き込みは成功しています)。

Unit NFC は電源を入れる前に挿しておいてください。 起動時に挿さっていないと EVT NFC_INIT_NG が出て、 後から挿しても再起動するまで復帰しません。

動作要件

  • Chrome / Edge / Opera (Web Serial API 対応ブラウザ)
  • ESP32-S3 は USB Serial/JTAG 内蔵のため、通常は追加ドライバ不要（Windows 10 以降 / macOS / Linux）
  • Windows 7 の PC では、そのままではシリアルポートが出てこないことがあります。警告デバイスのページの「Windows 7 の PC で使うとき」を参照し、同じ手順を試してください

ファームウェアをインストール

指静脈 = 中継基板 J3 (G5 / G6)、FC-1200 = DB9 (G7 / G8)、NFC = Grove Port A (G2 / G1)

お使いのブラウザは Web Serial API に対応していません。
Chrome, Edge, または Opera をお使いください。 シリアルポートへのアクセスが許可されていません。

動作確認 (シリアル 115200bps)

  • DEVICE — DEVICE timecard VER=… (機種識別 + 版数)
  • VEIN CAPTURE — 指を置くと VEIN CHARA <hex>。 モジュールがつながっていなければ ERR VEIN NO_MODULE
  • LOG DUMP — 起動直後のログ (USB 接続前に流れた分も残ります)

コマンドの一覧と詳細は console-protocol.md を参照してください。
