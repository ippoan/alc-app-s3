alc-hub BP Station

血圧計用 PC の測定台 ファームウェア書き込みツール — PC に USB で挿しっぱなしにして、カードの読み取りと 血圧計 (BLE) の測定値を PC のブラウザへシリアルで渡す端末です。 CoreS3 統合ハブは こちら、 NFC タイムカード端末は こちら。

対応機器

マイコンM5Stack Atom VoiceS3R (Atom EchoS3R / SKU C126-ECHO、8MB PSRAM)
カードリーダーM5 Unit NFC (SKU U216, ST25R3916) — Grove Port A
血圧計Omron HEM-6231T (BLE、既定 OFF)
接続USB-C で PC へ直結 (LAN / PoE は使いません)

PSRAM 非搭載の AtomS3 系には焼かないでください

ここで配布しているのは Atom VoiceS3R 専用のビルドです。 PSRAM (Octal 8MB) を前提に sdkconfig を組んでいるため、 AtomS3 / AtomS3 Lite などの PSRAM 非搭載機に焼いても PSRAM 無しのまま静かに起動します (エラーは出ません)。 BLE (血圧計) は PSRAM 上にヒープを取るので、その状態では血圧が動きません。

この端末はサーバへ直接送りません

ネットワークを持たないので、読んだカードも測った血圧も USB シリアルに JSON / EVT 行として出すだけです。 サーバへ届けるのは PC 側の画面 (キオスク) の仕事です。

書き込み手順

  1. 本体を USB-C ケーブルで PC に接続
  2. 箱出しの新品は本体ボタンを押しながら挿し直す — 工場出荷ファームは USB オーディオデバイスとして動いており、 そのままではシリアルポートが出てきません
  3. 下の「Install」ボタンをクリックし、シリアルポートを選択
  4. 書き込みが終わったら、ボタンから指を離して USB を挿し直す — 押したままだと起動のたびにダウンロードモードに入り、 焼けているのにアプリが動きません
  5. Unit NFC を Grove に挿して電源を入れ直す
  6. シリアルに EVT NFC_READY が出れば読み取り側は疎通完了

「焼けたのに動かない」ときに見るところ

シリアルに waiting for download や boot:0x30 (DOWNLOAD(USB/UART0)) が出ていたら、 ダウンロードモードに入ったままです。ボタンから指を離して挿し直してください (書き込みは成功しています)。

Unit NFC は電源を入れる前に挿しておいてください。 起動時に挿さっていないと EVT NFC_INIT_NG が出て、 後から挿しても再起動するまで復帰しません (Refs #152)。

コマンドラインで確認する場合、espflash monitor に --no-reset を付けないでください — 付けると端末がフラッシュスタブに留まってアプリが起動せず、 「反応が無い」ように見えます。

血圧計をつなぐ (既定は OFF)

血圧計は既定で無効です。BLE を起こすと内蔵 RAM を使うため、 使わない台では止めてあります。有効にするには、下のボタンを 1 → 2 → 3 の順に押します。押すとシリアルポートの選択が出るので、 測定台を選んでください (Chrome / Edge / Opera。ファームウェアの書き込みダイアログは 閉じてから)。

  1. 血圧計を使う — 端末に OMRON BP ON を送ります (OK OMRON BP=1 が返れば成功)。
  2. 再起動 — BLE を立てるかどうかは起動時に決まるので、再起動が要ります。 反応が無いときは USB を挿し直してください。
  3. 血圧計をペアリング — 先に血圧計をペアリング待ち (オムロンは Bluetooth ボタン長押しで -P- 点滅) にしてから押します。 押すたびに本体のボンド情報を消して 120 秒の受付を開き、 その間に見つけたペアリング待ちの血圧計と組みます。 成立したら押し直さないでください (組んだボンドを消してしまいます)。

ペアリングが済んだあと、血圧計で測定すると {"type":"blood_pressure",…} がシリアルに出ます。

ボタンが効かないとき・うまくいかないとき (シリアルに手で送る手順)

Web Serial 非対応のブラウザや、ボタンで進まないときは、シリアル端末 (115200bps) から次の順に送ります:

  1. シリアルに OMRON BP ON を送る (OK OMRON BP=1 が返る)
  2. 端末を再起動する — BLE を立てるかどうかは起動時に決まります (OFF のまま起動したときは EVT BLE_DISABLED omron_bp=0 が出ます)
  3. 血圧計をペアリング待ちにしてから PAIR を送る。 EVT PAIR_CLEARED → EVT PAIR_ARMED <秒> → EVT PAIR_OK で成立です (EVT PAIR_ERR / EVT PAIR_TIMEOUT は失敗)
  4. 測定すると {"type":"blood_pressure",…} がシリアルに出ます

ボンドは起動時に消えません

一度ペアリングすれば NVS に残るので、再起動のたびに操作は要りません。 消えるのは PAIR を明示的に送ったとき (「血圧計をペアリング」ボタンも同じ) だけです。 機器を入れ替えたときは PAIR をやり直してください。

動作要件

  • Chrome / Edge / Opera (Web Serial API 対応ブラウザ)
  • ESP32-S3 は USB Serial/JTAG 内蔵のため追加ドライバ不要
  • シリアルポートが出てこない場合は、本体ボタンを押したまま USB を挿し直す (ROM ダウンロードモード)。工場出荷ファームや、書き込んだファームが 起動直後に落ちる状態では、これが唯一の入り口です

ファームウェアをインストール

お使いのブラウザは Web Serial API に対応していません。
Chrome, Edge, または Opera をお使いください。 シリアルポートへのアクセスが許可されていません。

動作確認 (シリアル 115200bps)

  • PING — PONG 応答 (疎通確認)
  • DEVICE — DEVICE bp-station VER=… (機種識別 + 版数確認)
  • HEAP — FREE_PSRAM が 0 でないことを必ず確認。 0 なら PSRAM が載っていない機に焼いています (上の警告を参照)
  • OMRON STATUS — OMRON BP=1 / OMRON BP=0
  • LOG DUMP — 起動直後のログ (USB 接続前に流れた分も残ります)
  • AUTH STATUS — AUTH PAIRED <tenant> <id> / AUTH UNPAIRED

コマンドの一覧と詳細は console-protocol.md を参照してください。

カードをかざすと NFC IDm=… / 免許証 交付 … が出ます。 財布などにカードが 2 枚入っていて両方見えたときは、どちらか決められないので どちらも採らず nfc: 確定窓 …ms に 2 枚 — どちらも登録しない の警告だけが出ます (このとき音も鳴りません)。1 枚だけかざし直してください。

STATUS と OTA はこの端末にありません — 版数は DEVICE で確認

STATUS / OTA はどちらも ERR UNSUPPORTED (bp-station) を返します — ネットワークを持たない端末なので、更新は この画面から書き直すのが唯一の手順です。 版数の確認は DEVICE で行えます (上の一覧参照)。

読めたら音が鳴ります (点灯はしません)

Atom VoiceS3R には点灯表示がありません。読めたときは内蔵スピーカーが短く鳴ります。 「かざしたのに光らない」は異常ではありません。 音が出ない場合は speaker: 初期化失敗 がログに出ていないか確認してください (鳴らなくても読み取りそのものは動きます)。
